Testing inference: how long must the trigger be?¶

Retrieval is cued by only a fragment of the stored motif. This notebook measures the minimal trigger duration N_trigger_time (in ms) such that injecting the first N_trigger_time bins of the target suffices for the network to re-emit the full pattern in the evoked window. It probes the temporal completeness property of the memory (pattern completion along time).

Notebook summary¶

Pipeline¶

  1. Load the trained <datetag>_vanilla.pth (same weights as notebooks 11/13/14 - no retraining here).

  2. Single trial with a partial trigger (80 % of num_delay) -> F1 + raster.

  3. Scan N_trigger_time = 0 .. num_delay-1 x N_cv=11 seeded repetitions (get_scores_fraction) -> per-length F1 (mean +/- std), cached as <datetag>_trigger_time.npz (+ .lock); plot trigger_time_score.pdf.

Main outputs¶

  • cache ../cached_data/<datetag>_trigger_time.npz (arrays N_trigger_times, scores_np);

  • figures trigger_time.pdf (raster) and trigger_time_score.pdf (F1 vs trigger length).

Notes¶

  • get_input_spikes(N_trigger_time=...) truncates the cue; num_delay=41 is the maximum (and odd, by construction). With a 80 % trigger (33 ms) retrieval already collapses to f1 ~ 0.32 here: the readout needs nearly the full SM window to lock onto the motif.

  • The comparison slices are the usual evoked-window convention of notebook 11.

  • scores_np is (num_delay, N_cv) = (41, 11): F1 is the mean +/- s.d. over N_cv seeded cue realisations (pattern_object(seed=...) + torch.manual_seed, seed += 1 per repetition, nb 20-style), scored against the clean frozen_target. The cache is saved after every trigger length, so an interrupted scan can resume.

Retrieval from a partial trigger¶

Single trial: N_trigger_time = 0.80 * num_delay (~33 ms instead of 41). Scored on the full evoked window against the complete target - the last 0.20 * num_delay ms of the motif are never shown to the network and must be completed from memory.

[5]:

# Partial trigger: get_input_spikes stops copying the target after N_trigger_time bins.

with torch.no_grad():
    target = hd.pattern_object()
    N_trigger_time = int(hd.opt.num_delay*.80)
    target_full = torch.nn.functional.pad(target, (opt.N_pretime, opt.N_pretime))
    input_spikes = hd.get_input_spikes(target=target, N_trigger_time=N_trigger_time)
    _, _, spikes = hd.forward_pass(input_spikes)
    spikes_evoked = spikes[:, :, (hd.opt.N_pretime+hd.opt.num_delay):(hd.opt.N_time+hd.opt.N_pretime)]
    target_evoked = target[:, :, hd.opt.num_delay:]
    precision, recall, f1_score = get_scores(spikes_evoked, target_evoked)
    print(f'precision = {precision:.3f}\t recall = {recall:.3f}\t f1_score = {f1_score:.3f} ')

Sweep: F1 as a function of the trigger duration¶

get_scores_fraction: one forward pass per N_trigger_time in 0 .. num_delay-1, scoring the evoked window with get_f1score. The curve reveals the critical trigger length at which retrieval emerges (and the floor, f1 ~ 0, for spontaneous-only cues). Cached as <datetag>_trigger_time.npz under the .lock protocol.

[7]:

# One cue realisation per repetition (seeded nb 20-style), truncated to N_trigger_time
# bins and scored against the clean frozen_target; the cache is saved after every
# trigger length so an interrupted run can resume from the file.

def get_scores_fraction(N_cv=opt.N_cv):
    N_trigger_times = np.arange(hd.opt.num_delay)
    scores_np = np.zeros((N_trigger_times.size, N_cv))
    target_evoked = hd.pattern_object.frozen_target[:, :, hd.opt.num_delay:]
    seed = hd.opt.seed # base seed, incremented per repetition (nb 20 convention)
    for i_trigger_time in trange(N_trigger_times.size):
        N_trigger_time = N_trigger_times[i_trigger_time]
        for i_cv in range(N_cv):
            with torch.no_grad():
                torch.manual_seed(seed)
                target_ = hd.pattern_object(seed=seed)
                input_spikes = hd.get_input_spikes(target=target_, N_trigger_time=N_trigger_time)
                _, _, spikes = hd.forward_pass(input_spikes)
                spikes_evoked = spikes[:, :, (hd.opt.N_pretime+hd.opt.num_delay):(hd.opt.N_time+hd.opt.N_pretime)]

                scores_np[i_trigger_time, i_cv] = get_f1score(spikes_evoked, target_evoked)
                seed += 1

        np.savez(npy_filename, N_trigger_times=N_trigger_times, scores_np=scores_np) # incremental save

    return N_trigger_times, scores_np
